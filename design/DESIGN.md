# 墨读 · Legado Desktop UI 设计规范

> 版本：v0.3（2026-10-30，补齐 Phase 2 及后续功能界面）
> 可交互原型：[`prototype/index.html`](prototype/index.html)
> 截图：[`screenshots/`](screenshots/)
> 设计方向：深色沉浸 · 左侧边栏 · 阅读 / 书源 / 书架优先

---

## 1. 设计定位

**一句话**：一个能连续读三小时不累、又能像专业工具一样管理上百个书源的 Windows 阅读器。

| 关键词 | 含义 |
| --- | --- |
| 静 | 阅读页只有文字；工具栏按需出现 |
| 密 | 书架与书源页信息密度高，扫读效率优先 |
| 快 | 键鼠优先，常用动作不超过一次点击或一个快捷键 |
| 暖 | 深色不用纯黑，强调色取暖琥珀，避免冷冰冰的工具感 |

参考气质：Linear 的深色层次、Arc 的克制圆角、纸质书的版式，以及 reader-main 已验证的“主从管理”结构。

---

## 2. 设计原则

1. **阅读第一**：进入阅读页后，除正文外的一切都可以隐藏；正文列宽、行高、字号永远可调。
2. **深色不是纯黑**：基础背景 `hsl(220 14% 6%)`，用表面层级和 1px 边框建立结构，不用大面积阴影。
3. **状态不只靠颜色**：书源状态 = 圆点 + 文案 + 延迟；错误 = 图标 + 人话 + 下一步动作。
4. **动效服务于方向**：只用于翻页、抽屉、面板出现，时长 120–320ms；尊重 `prefers-reduced-motion`。
5. **原型不等于实现**：`design/prototype` 只用于评审，产品代码仍在本仓库 `frontend/` 中另写。

## 3. 视觉系统

### 3.1 颜色 Token

所有颜色以 HSL 定义在 `prototype/styles.css :root`，组件只引用语义变量。

| Token | HSL | 近似 HEX | 用途 |
| --- | --- | --- | --- |
| `--bg` | `220 14% 6%` | `#0D0F12` | 应用背景 |
| `--surface` | `220 14% 9%` | `#14161A` | 侧栏、卡片底 |
| `--surface-2` | `220 13% 12%` | `#1A1D22` | 输入框、次级面板 |
| `--surface-3` | `220 11% 16%` | `#242830` | 悬浮、激活底 |
| `--border` | `220 10% 17%` | `#272A31` | 常规描边 |
| `--border-strong` | `220 9% 25%` | `#3A3E47` | 悬浮/聚焦描边 |
| `--text` | `40 12% 91%` | `#EAE7E1` | 主文字 |
| `--text-2` | `220 7% 68%` | `#A6A9B1` | 次要文字 |
| `--text-3` | `220 6% 51%` | `#7C8089` | 辅助说明（AA） |
| `--accent` | `32 56% 60%` | `#D9A25E` | 强调、进度、激活 |
| `--accent-strong` | `32 62% 68%` | `#E5B77B` | 强调文字、图标 |
| `--accent-2` | `210 32% 66%` | `#93A8C4` | 少量冷色信息 |
| `--success` | `145 32% 56%` | `#6FBF8C` | 在线、成功 |
| `--warn` | `38 60% 58%` | `#D6A24E` | 需验证、慢源 |
| `--danger` | `8 52% 62%` | `#D0786C` | 错误、删除 |

使用规则：

- 主按钮：暖琥珀渐变 + 深色文字（对比 ≥ 4.5:1）。
- 强调色只用于“当前、进度、主操作”，一屏不超过 3 处大面积使用。
- 状态圆点必须配文字，不允许只靠红/绿区分。
- 阅读主题是独立变量组，不影响 App shell 的深色。

### 3.3 字体

| 角色 | 字体栈 | 字号 / 行高 | 用途 |
| --- | --- | --- | --- |
| UI | Segoe UI → Microsoft YaHei UI → Noto Sans SC | 14 / 1.5 | 全局 |
| 标题 | 同 UI，但使用衬线感 | 27 / 1.25 | 页面标题 |
| 阅读标题 | Source Han Serif SC → Noto Serif SC → Songti SC → SimSun | 1.55 × 正文字号 | 章节名 |
| 阅读正文 | 同上；可选楷体 / 黑体 | 16–30 px（默认 19）/ 1.6–2.2（默认 1.9） | 正文 |
| 数字 / 规则 | JetBrains Mono → Cascadia Code → Consolas | 10.5–11.5 | URL、规则、日志 |

规则：

- 正文字号最小 16px；行高最小 1.6；段距 0.4–1.6em（默认 0.9）。
- 中文正文首行缩进 2em，两端对齐，标点遵循行首禁则。
- 正式版建议内置思源宋体子集，避免依赖用户系统字体。

尺寸约定：

- 最小窗口 1024×700；设计基准 1440×900；4K 下按系统缩放。
- 侧栏 232px，<1180px 自动折叠为 72px 图标栏。
- 内容最大宽 1360px，居中。
- 阅读正文列 620–880px（默认 720），页间距 64px。
- 阅读抽屉 356px；TTS 条最大 680px。
- 设置：200px 二级导航 + 内容面板，内容最小高度 560px；阅读设置采用 1fr + 300px 实时预览。
- 本地：导入 banner + 7 列文件表；窄屏逐级隐藏“内容”“大小”“最近打开”列。

## 6. 页面规范

### 6.1 书架

![书架](screenshots/shelf.png)

**结构**：页面标题 → 继续阅读卡 → 分组标签 + 排序 → 书籍网格/列表。

**关键行为**

- 点击继续阅读卡或“继续阅读”直接进入阅读器。
- 网格 / 列表切换即时生效；列表显示缓存章节数与进度。
- 分组标签过滤书架；分组名同步到顶栏面包屑。
- 书籍卡 hover 上浮 2px、封面轻微放大；键盘 Enter/Space 打开。
- 更新徽标只在有更新时出现；进度条只对有进度的书显示。

**状态**

- 空分组：一句引导文案 + 切回“全部”。
- 封面缺失：使用渐变底 + 书名首字，不用灰色占位图。

### 6.2 发现 / 聚合搜索

![搜索](screenshots/search.png)

**结构**：大搜索框 → 范围 chips → 进度条 → 结果列表 → 建议词。

**关键行为**

- 提交后逐源显示进度（`正在解析 墨香居…` → `合并重复结果…`）。
- 结果按书名合并，来源以标签展示名称与延迟；同名不同源合并为一条。
- “加入书架”成功后按钮变“已在书架”，不弹确认框。
- 建议词一键发起搜索。
- 空结果 / 全部超时：展示失败源数量 + “重试失败书源”，不展示堆栈。

**文案规则**

- 进度文案用“正在做什么”，不用百分比裸数字。
- 错误文案包含下一步动作，例如“3 个书源需要验证 → 去书源页处理”。

### 6.3 书源管理

![书源](screenshots/sources.png)

**结构**：操作栏 → 左列表（320px）+ 右编辑器（自适应）→ 测试控制台。

**关键行为**

- 左列表支持搜索名称/URL；选中项左侧 2px 琥珀线 + 浅色底。
- 右侧 7 个规则页签：概览、搜索、发现、详情、目录、正文、其他。
- 规则字段用等宽字体；长文本用 textarea；保存按钮常驻右上。
- 启用开关即时更新左列表状态圆点与延迟文案。
- 测试控制台：运行中禁用按钮，日志逐行追加，成功后状态变“成功 · N 条”。
- 大列表（>100）需要虚拟滚动；原型未体现。

**字段密度**

![书源 · 紧凑模式](screenshots/sources-dense.png)

编辑器采用“分区 + 双列”结构：

- 字段按语义分组（基础信息 / 请求配置 / 备注），组标题带一句说明；
- 短字段两列并排，URL、请求头、注释等 `wide` 字段通栏；
- 每个字段：10.5px 标签 + 必填徽标 + 30px 输入框 + 可选 9.5px 说明；
- 右上角 meta 显示“9 字段 · 2 必填”，并提供 舒适 / 紧凑 切换；
- 紧凑模式：输入框 26px、行距 6px、隐藏字段说明，一屏多看约 40% 字段；
- 控制台固定 132px，运行日志逐行追加。

### 6.4 阅读器

![阅读器 · 墨夜](screenshots/reader-ink.png)
![阅读器 · 纸白](screenshots/reader-paper.png)
![阅读器 · 排版抽屉](screenshots/reader-settings.png)

**两种模式**

| 模式 | 行为 |
| --- | --- |
| 横向分页（默认） | 按可视高度切页；左右各 11% 区域点击翻页；←/→/空格；页码与进度条同步 |
| 滚动 | 单列连续滚动；隐藏页码；保留章节进度 |

**界面层**

1. 顶栏（62px）：返回、书名、章节、目录、朗读、排版、更多；2.6s 无操作自动隐藏，鼠标移动或打开抽屉时出现。
2. 正文：页宽 720，行高 1.9，段距 0.9em，首行缩进 2em。
3. 底栏（46px）：时间、阅读进度、页码。
4. 右侧排版抽屉：主题、字体、字号、行高、段距、页宽、翻页模式、恢复默认；所有调整实时重排。
5. 左侧目录抽屉：搜索 + 章节列表，当前章节琥珀高亮。
6. TTS 条：播放/暂停、段落信息、进度、倍速、音色。
7. 选中文字浮动工具条：复制、搜索、书签。

**边界**

- 翻到最后一页时不再响应；到达章末给“下一章”提示（二期）。
- 调整字号/页宽后保持阅读位置（按字符位置映射，原型只重置到当前页）。
- 长章节分页需要标点行首禁则、英文/数字不拆分。

### 6.5 设置

![设置 · 阅读](screenshots/settings-reading.png)

设置采用二级导航（200px）+ 内容面板：

- **阅读**：翻页模式、字号、行高、段距、页宽、简繁、自动阅读间隔、朗读引擎；右侧实时预览随字号/行高/主题变化。
- **外观**：四套阅读主题、侧栏默认展开、减少动效、界面密度、启动与关闭行为。
- **存储**：数据目录、便携模式、缓存占用与分类、缓存策略、清理/打开目录。
- **快捷键**：按键方案 + 9 组快捷键 + 恢复默认。
- **网络**：代理、系统代理、书源并发、超时、局域网访问、DoH / HTTP2 / 证书错误。
- **备份**：WebDAV 配置、自动同步、本地备份列表（时间/大小/来源）、立即备份与恢复。

| --- | --- |

其他约定：

- 所有可点击元素 hover 120ms 内反馈；主按钮按下位移 1px。
- 抽屉从左/右滑入 320ms；点击正文区或 `Esc` 关闭。
- 命令面板支持 ↑↓ 选择、Enter 执行、Esc 关闭。
- 复制失败（剪贴板未授权）给出可操作提示，不抛原始错误。

## 8. 状态与文案

| 状态 | 表现 |
| --- | --- |
| 加载 | 进度条 + 正在做什么；超过 3s 显示“仍在等待 <源名>” |
| 空 | 一句解释 + 一个明确动作（导入/切换分组/重试） |
| 错误 | 图标 + 人话 + 下一步；不展示堆栈、异常类名 |
| 离线 | 顶栏状态点变灰 + “离线，将使用缓存” |
| 超长文本 | 单行省略；详情页再展开 |
| 危险操作 | 二次确认，默认焦点在“取消” |

文案规范：

- 动词开头，例如“导入本地”“重试失败书源”。
- 不使用“未知错误”“操作失败”这类无信息文案。
- 技术细节放进日志页，不放在主界面。

## 9. 可访问性

- 正文与背景对比 ≥ 4.5:1；辅助文字 ≥ 4.5:1；禁用态 ≥ 3:1。
- 焦点态：2px 琥珀描边 + 2px 偏移，所有按钮/输入/卡片可 Tab 到达。
- 不以颜色作为唯一状态信号：书源状态配文字，错误配图标。
- 点击目标 ≥ 32×32；阅读翻页区 ≥ 11% 宽度。
- 尊重 `prefers-reduced-motion`，关闭翻页/抽屉动画。
- 阅读字号最小 16px；不强制全大写；中文行高 ≥ 1.6。
- 高 DPI：图标使用矢量 SVG，边框 1px 不随缩放变粗。

## 11. 原型使用说明

直接双击 `prototype/index.html` 即可（无外部依赖、无构建）。也可以用本地服务：

```bash
cd legado-desktop
./gradlew :server:run --args="--port 8090 --token dev --static-dir design/prototype"
# 打开 http://127.0.0.1:8090/
```

调试参数：

| 参数 | 示例 | 作用 |
| --- | --- | --- |
| `view` | `?view=sources` | 直达书架/发现/书源/本地/统计/设置 |
| `q` | `?view=search&q=长夜行` | 自动执行搜索 |
| `reader` | `?reader=1` | 打开阅读器 |
| `page` | `?reader=1&page=2` | 跳到指定页 |
| `theme` | `?reader=1&theme=paper` | ink / paper / eye / black |
| `mode` | `?reader=1&mode=scroll` | paged / scroll |
| `panel` | `?reader=1&panel=settings` | settings / toc |
| `tts` | `?reader=1&tts=1` | 显示朗读条 |
| `settingsPanel` | `?view=settings&settingsPanel=storage` | reading / appearance / storage / shortcuts / network / backup / about |
| `density` | `?view=sources&density=dense` | comfortable / dense |
| `editorTab` | `?view=sources&editorTab=search` | overview / search / explore / detail / toc / content / other |
| `format` | `?view=local&format=PDF` | 全部 / TXT / EPUB / PDF |
| `modal` | `?modal=detail&book=changye` | detail / switch / import / backup / restore / cache / login / about / update / welcome |
| `tab` | `?modal=backup&tab=remote` | 备份子页；导入子页 file/url/deep/json |
| `tasks` | `?tasks=1` | 打开任务中心 |
| `drawer` | `?reader=1&drawer=bookmarks` | toc / bookmarks / search |

原型中的书源、书籍、章节与统计均为假数据，封面为生成素材，仅用于设计评审。

## 12. 与产品实现的映射

- **Token**：`prototype/styles.css` 的 `:root` 与 `.reader[data-theme]` 直接对应未来的 `frontend/src/styles/tokens.css`。
- **组件**：建议在 Vue 中拆为 `AppShell`、`Sidebar`、`Topbar`、`BookGrid`、`ContinueCard`、`SearchHero`、`ResultCard`、`SourcePanel`、`SourceEditor`、`RuleTabs`、`FormSection`、`FormField`、`DensityToggle`、`TestConsole`、`SettingsNav`、`SettingsPanel`、`PreviewPage`、`LocalTable`、`BackupRow`、`ReaderView`、`ReaderChrome`、`ReaderPager`、`ReaderSettings`、`TocDrawer`、`TtsBar`、`CommandPalette`、`Toast`。
- **Phase 2+ 组件**：`Modal`、`SidePanel`、`BookDetailPanel`、`SourceSwitchModal`、`ImportWizard`、`BackupDialog`、`CacheManager`、`TaskDrawer`、`LoginDialog`、`AboutDialog`、`WelcomeDialog`，与原型中的同名区块一一对应。
- **分页**：产品实现不能直接照搬原型的分页脚本；需要按行度量 + 标点禁则 + 图片块处理（可参考 reader-main 的 `useHorizontalPaging` 思路，但独立实现）。
- **阅读位置**：记录“章节 + 字符偏移”，不要只记录页码；字号变化后按偏移恢复。
- **主题**：阅读主题与 App shell 主题分离；本期 App shell 固定深色。
- **图标**：原型内联 Feather 风格 SVG，产品可沿用同一套路径，避免引入大图标库。
